# Approach review triage

- **Reader and writer reuse:** Keep conditional. Check file type, permissions and concurrent-change behavior before choosing the existing boundaries; add or adapt a boundary if it cannot preserve the required behavior.
- **Host evidence:** Keep open until tested. Do not turn flag presence into a claim that every host offers a usable control.
- **Independent review:** Not completed. The assigned reader was blocked by harness process registration; the main agent performed the scoped review.
- **Scope:** Retain one-ticket-at-a-time delivery and preserve uncommitted later-slice changes.
